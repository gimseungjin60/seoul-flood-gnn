# 17. 시공간 GNN 단기 예측: 사전 고정 규칙

고정일: 2026-11-09. 이 문제로 어떤 모델도 돌리기 전에 정했다. 코드 기준은 [src/analysis/t1_st_rules.py](../src/analysis/t1_st_rules.py)의 상단 docstring과 상수다. 이 문서와 코드가 다르면 코드가 우선한다.
범위: 서울시 강남구 센서 (2026-06-01~08-31, 예측 대상 17개 + 입력 센서 31개).

## 왜 방향을 바꾸나
- 센서 없는 곳 추정(T2)에서는 도로거리, 고도 방향, 랜덤 그래프가 모두 같은 결과였다([docs/15](15_graph_alternatives_result.md)). 그때 GNN은 이웃의 **지금 이 순간 값**만 받았다. 그래서 관로망에서 그래프가 의미를 가지는 **시간차**(위쪽 물이 몇십 분 뒤 아래로 내려옴)를 쓸 수 없었다.
- 이번에는 **센서가 있는 곳의 10분·30분 뒤 수위**를 예측한다. 이웃 센서의 **지난 1시간 흐름**을 함께 보는 시공간 GNN을 쓴다.
- 예측 지점의 과거 관측이 있는 문제(T1)라서, 학습 구간 관측으로 만든 **상관 그래프**도 쓸 수 있다.
- 연구 주제도 "수위 추정"에서 **"수위 추정·예측"**으로 넓힌다. T2 결과(docs/08~16)는 그대로 둔다.

## 설정
| 항목 | 내용 |
|---|---|
| 자료 | 2026 재비교와 같다. 10분 블록, 센서 48개, 평가 이벤트 13개, 시간순 5폴드 + purge 24시간 |
| 문제 | 시각 t까지의 정보로 t+10분, t+30분 수위를 예측. 입력 창 60분 |
| 예측 대상 | 평가 대상 17개(연속 기록). 나머지 31개는 입력으로만 |
| 입력 | 센서별 최근 60분 수위(평소 대비, 규모로 나눔), 관측 여부, 최근접 강우량계의 지난 강우, 시간대. **미래 강우는 쓰지 않음** |

## 비교 모델 (하이퍼파라미터 탐색 없음)
| | 모델 | 역할 |
|---|---|---|
| M0 | 직전 값 그대로 | 가장 단순한 기준 |
| M1 | 자기 이력 선형(Ridge) | |
| M2 | 자기 이력 + 강우·시간대 선형 | **주 비교 기준** |
| M3 | M2 + 도로거리 이웃 5개의 최근 변화 | 그래프 학습 없이 이웃을 쓰는 기준 |
| G-road | 시공간 GNN, 도로거리 최근접 5개 그래프 | |
| G-corr | 시공간 GNN, 상관 그래프(학습 구간 10분 변화량 상관 상위 5개) | |

- **GNN 구조:** 센서별 GRU(은닉 32)가 60분 흐름을 요약하고, 강우·시간대와 합친 뒤, 관측된 이웃만 섞는 메시지 전달 2층을 거쳐 10분·30분 뒤 변화를 함께 출력한다.
- **학습 설정:** 30에폭, 시드 0·1·2 평균, 비 사건 구간 가중 5. 값은 T2 GNN과 같다.
- 정규화와 상관 그래프는 **학습 구간만으로** 만든다. 기점 t의 예측에는 t 이후 값이 들어가지 않는다. 이를 누수 테스트([tests/test_t1_st.py](../tests/test_t1_st.py))로 확인했다.

## 판정 (이 다섯 가지뿐)
지표는 비 사건 구간 평균 오차(이벤트 MAE, 예측 대상 시각이 사건 창 안인 표본)다. 부트스트랩은 이벤트 13개를 2000회 복원추출(시드 0)한다. 판정은 차이의 95% CI로 한다.

| | 비교 | 판정 |
|---|---|---|
| F1 주 | 30분 뒤: G-road − M2 | 상한 < 0 "GNN이 강우+자기이력 선형을 넘음" / 0 포함 "구분 불가" / 하한 > 0 "선형보다 나쁨" |
| F2 주 | 30분 뒤: G-corr − M2 | F1과 같음 |
| F3 그래프 구조 | F1·F2에서 "넘음"인 그래프만: 그 GNN − M3 | 상한 < 0일 때만 "그래프 구조 효과" |
| F4 보조 | 10분 뒤: G-road − M2, G-corr − M2 | 같은 3단계로 따로 보고 |
| F5 기준선 확인 | 30분 뒤: M2 − M0 | 강우·자기이력 선형이 "직전 값 그대로"보다 나은지 |

- GNN 그래프 2개를 비교했다는 사실을 함께 보고한다. 다중 비교 보정은 하지 않는다.
- 결과가 어떻든 보고한다. "시간 예측에서도 구분 불가"도 결론이다.

## 한계
- 상관 그래프는 센서가 있는 곳에서만 만들 수 있다. 센서 없는 곳 추정에는 쓸 수 없다.
- 이벤트가 13개뿐이다. 어느 그래프도 실제 관로 연결은 아니다.
- 7주차 기준 모델 단계(2025, 1분 자료)에서도 선형 모델은 "직전 값 그대로"와 거의 차이가 없었다. 이번 문제도 넘기 어려울 수 있다.

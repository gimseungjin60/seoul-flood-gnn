# T2 GNN 결과 (센서 하나 가리고 맞히기, 서울시 강남구 센서 18개, 2025-06~08)

사전 고정 규칙은 `src/analysis/t2_gnn.py` 상단 docstring(실행 전 커밋 `621818c`), 판정은 `src/analysis/t2_gnn_eval.py`, 수치는 `data/processed/gangnam_t2_gnn_report.txt`와 `gangnam_t2_gnn_ci.csv`다.
이 검증은 타깃의 기저선·규모를 안다는 가정 하의 상대 상승폭 추정이며 절대수위 추정이 아니다. test 구간은 쓰지 않았다.

## 설정 (그리드 없음, 사전 고정)
- 기존 T2 LOSO와 같은 틀: 타깃 센서 1개를 통째로 제외(18번), 시간순 5폴드, purge 24시간, 10분 블록, 평가 이벤트 8개.
- GNN: 인코더(32) + 메시지 전달 2층, 이웃은 도로거리 k=5 최근접(가중 1/d, 관측된 이웃만), 학습은 나머지 17개 센서를 비율 0.3으로 가리고 맞히기, 이벤트 구간 손실 가중 5, Adam 1e-3, 30에폭, 시드 3개 평균. dense 인접행렬(그래프 라이브러리 미사용).
- 타깃의 과거값은 입력·학습에 쓰지 않는다(누수 테스트 8개 통과, `tests/test_t2_gnn.py`).

## 판정 (사전 고정 기준)
- 주 판정 GNN − IDW = +0.80 mm, 95% CI [−0.29, +2.08] → **구분 불가**.
- 보조 판정 GNN − (4) = −0.19 mm, 95% CI [−0.53, +0.22] (상한이 0 이상).
- 결론: GNN은 IDW와 통계적으로 구분되지 않고 선형 이웃 모델(4)과도 구분되지 않는다. **"그래프 구조 효과"로 보고하지 않는다.**

## 참고 (판정에 쓰지 않음)
- val 이벤트 7·8번(하이퍼파라미터 선택에 쓰이지 않음)에서는 GNN이 IDW보다 이벤트별로 0.67, 0.71 mm 낮았다. 이벤트 2개뿐이라 CI는 계산하지 않았고, 8개 전체에서는 반대 방향(+0.80)이므로 결론에 쓰지 않는다.
- 큰 사건 5·8번을 제외하면 GNN − IDW = +1.12, GNN − (4) = +0.02 mm.
- 센서별로 GNN이 IDW보다 낮은 센서는 7/18, (4)보다 낮은 센서는 10/18.

## 한계
- 이벤트 8개뿐이라 CI가 넓다. 학습 풀이 17개 센서뿐이고 그래프는 도로거리 근사(실제 관로 아님)다.
- 사후 민감도 분석(k, 마스크 비율, 이벤트 가중 그리드)은 아직 돌리지 않았고, 돌려도 "사후, 판정에 쓰지 않음"으로 표시한다.

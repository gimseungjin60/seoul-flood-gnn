## 2. 다음 할 일 (순서대로)
1. **2차 중간발표 덱(이번 주, 10분):** 1차 이후 진행만 다루고, 1차 내용은 1~2장으로 요약한다. 작성 규칙은 평가자 관점, 개조식, 핵심 수치 1~2개다.
   - 흐름: 방향 전환 → 시차 있음 → 30분 구분 불가 → 60분 GNN 근소 우위(시간 모델, 물 빠지는 구간) → 큰 상승은 미래 강우가 핵심 → 다음 단계
   - 그림 후보:
     - 무엇을 더하면 오차가 줄었나(이웃 0.2, GNN 0.5, 미래 강우 4.1 mm)
     - 큰 상승 맞힘 건수(1/94 → 25/94)
     - 60분 뒤 하강·상승 구간별 오차
   - 그림 함수는 `src/analysis/figures_2026.py`에 추가한다.
2. **대시보드(팀원 담당)에 전달할 것:**
   - 30분 뒤 예상선은 M2(선형)로 한다([docs/19](19_t1_st_gnn_result.md)).
   - 예상선은 경보가 아니라는 안내를 넣는다([docs/25](25_t1_warning_result.md)).
   - 센서 없는 곳 비교선은 IDW로 한다([docs/15](15_graph_alternatives_result.md)).
3. **최종까지 연구 후보:**
   - 실제 강우 예보(초단기 강수 예측·레이더)로 상한 실험을 다시 확인한다. 과거 예보 자료를 구할 수 있는지부터 확인한다.
   - 미래 강우를 넣은 GNN.
4. **11주차 일지 갱신(남아 있음):**
   - 주제 문구를 "추정·예측"으로 바꾸고, 시공간 GNN 결과를 반영한다.
   - 양식은 `docs/logs/11주차/11주차 학습일지.docx`를 참고한다.
   - 10주차 일지를 따로 내야 하는지도 아직 확인하지 않았다.

## 3. 실행 메모
- 실험은 **하나씩** 돌린다. 동시에 돌리면 CPU 스레드가 겹쳐 각각 2배 이상 느려진다. 혼자 돌릴 때 걸리는 시간은 다음과 같다.

| 실행 | 시간 |
|---|---|
| `t1_long` (입력 120분 전체) | 약 2시간 |
| `t1_nbr` | 약 1시간 45분 |
| `t1_oracle` | 10초 |

- 예측 파일(`gangnam2026_t1_*_predictions.npz`, `gangnam2026_t2_*`)은 git에서 제외된다. 판정·대시보드에 필요하므로 지우지 않는다.
- 콘솔 한글 오류가 나면 `$env:PYTHONUTF8="1"`을 설정한다. 테스트는 `python -m tests.test_xxx`로 돌린다(가상환경에 pytest 없음).

## 4. 환경 메모
- 가상환경에 추가한 패키지는 `rasterio`, `streamlit`, `streamlit-folium`이다. 모두 `requirements.txt`에 반영했다.
- DEM 원본은 `data/raw/dem/`에 있고 git에서 제외된다. 없으면 `python -m src.data.sensor_elevation_2026`이 다시 내려받는다.
- 실습일지 제출본은 `docs/logs/`(git 제외), 그림은 `docs/figures/`(용도별)에 둔다.

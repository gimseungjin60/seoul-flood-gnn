## 2. 진행 중: 시공간 GNN 예측 실행
- 2026-11-09 밤에 `python -m src.analysis.t1_st`를 시작했다(약 55분). 결과는 `data/processed/gangnam2026_t1_st_predictions.npz`에 저장되며 git에서 제외된다.
- **다음에 시작할 때 먼저 확인할 것:**

  2. 없으면(실행이 중간에 끊긴 경우) 다시 실행: `python -m src.analysis.t1_st` → `python -m src.analysis.t1_st_eval`

## 3. 다음 할 일 (순서대로)
1. **판정 후 결과 문서 docs/19 작성.** 다음을 정리한다.
   - F1~F5 판정
   - 10분·30분 MAE 표
   - 센서별 결과
   - 판정 그림: `src/analysis/figures_2026.py`에 함수를 추가한다(`graph_diff`와 같은 방식).
   - README 2절과 11절, 문서 목록을 갱신한다.
2. **결과에 따른 정리:**
   - **GNN이 M2를 넘고 F3까지 통과:** "시간 예측에서는 그래프 구조 효과 확인"으로 정리하고, 대시보드 예측선은 GNN으로 한다.
   - **넘지만 F3 미통과:** "GNN이 낫지만 그래프 구조 덕분이라고 보기는 어려움"으로 정리한다.
   - **구분 불가 또는 나쁨:** "시간 예측에서도 구분 불가"로 정리하고, 대시보드 예측선은 M2(선형)로 한다.
3. **대시보드:** 센서 그래프에 "30분 뒤 예상" 선을 추가한다. 센서 없는 곳 비교선은 IDW를 기본으로 한다(docs/15 결과).
4. **11주차 일지 갱신:**
   - 주제 문구를 "도로망 기반 공간 그래프를 활용한 하수관로 수위 **추정·예측** 연구"로 바꾼다.
   - 시공간 GNN 결과를 실습결과에 추가하고, 그림을 바꾸거나 더한다.
   - 생성 스크립트는 세션 임시 폴더에 있었으므로 다음에는 새로 만든다. 양식은 `docs/logs/11주차/11주차 학습일지.docx`를 참고한다.
5. **아직 답이 없는 것:** 10주차 일지(11.2~11.8)를 따로 내야 하는지 확인한다.

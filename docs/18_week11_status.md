## 4. 환경 메모
- 이번 주에 가상환경에 새로 설치한 패키지는 `rasterio`(센서 고도), `streamlit`, `streamlit-folium`(대시보드)이고 모두 `requirements.txt`에 반영했다.
- DEM 원본(49 MB)은 `data/raw/dem/`에 있고 git에서 제외된다. 없으면 `python -m src.data.sensor_elevation_2026`이 다시 내려받는다.
- 예측 파일(`gangnam2026_t2_*`, `gangnam2026_t1_*` predictions)은 git에서 제외된다. 대시보드 비교선과 판정에 필요하므로 지우지 않는다.
- 실습일지 제출본은 `docs/logs/`(git 제외), 일지와 발표에 쓴 그림은 `docs/figures/`(용도별)에 둔다.
- 이 Mac(macOS)에서는 Python 3.13 venv(`/opt/homebrew/bin/python3.13 -m venv .venv`)로 실행했다. 시스템 Python 3.9는 `str | None` 문법 때문에 안 된다. 그림의 한글 폰트는 `AppleGothic`을 대체로 추가했다.

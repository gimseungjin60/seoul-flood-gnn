## 2. 학습된 연결은 거의 균등해졌다 (참고, 폴드 1·시드 0)
- 학습된 연결 점수의 **97.9%가 0**이다. 점수 상위 10개도 모두 0이다.
- 연결 점수가 모두 0이면 softmax는 **관측된 이웃 전체를 똑같이 평균**한다. 따라서 G-adapt는 사실상 "모든 이웃의 균등 평균" 그래프로 수렴했다.
- 원인은 relu 때문으로 보인다. 초기값이 작아서 점수 대부분이 음수에서 시작했고, relu를 지나면 0이 되어 학습 신호(기울기)를 받지 못했다. Graph WaveNet에서 알려진 형태의 문제다. 규칙에 따라 설정은 바꾸지 않았다.
- 이 상태에서도 결과가 도로거리·상관 그래프와 같다(차이 0.1 mm 이내). 이는 **"어떤 이웃을 고르느냐"가 성능에 거의 영향을 주지 않는다**는 앞선 결과들과 같은 방향이다.
  - 도로거리 = 랜덤([docs/15](15_graph_alternatives_result.md)), 도로거리 ≈ 상관([docs/19](19_t1_st_gnn_result.md)).

## 3. 해석
- 이번 결과만으로 "연결 학습은 효과가 없다"고 말할 수는 없다. 학습이 사실상 일어나지 않았기 때문이다.
- 말할 수 있는 것은 두 가지다.
  1. 균등 평균 그래프도 정해 둔 그래프들과 같은 성능을 낸다.
  2. 이 자료(이벤트 13개)에서 그래프 구조의 차이는 성능 차이로 나타나지 않는다.
- 연결 학습을 제대로 시험하려면 초기값이나 relu 같은 설정을 바꿔야 한다. 이는 새 규칙의 "사후" 실험이 된다. 이벤트 13개로 연결 2,256개를 학습하는 과적합 위험도 그대로 남는다. 우선순위는 낮다고 본다.

## 4. 한계
- 연결 점수는 폴드 1·시드 0 모델 하나에서만 확인했다. 학습한 연결은 관로 연결의 증거가 아니다.

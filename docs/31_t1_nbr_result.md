# 31. 60분 뒤 GNN 우위는 이웃 덕분인가, 재현되나: 결과

규칙: [docs/30](30_t1_nbr_rules.md) (커밋 `71184d2`, 실행 전 고정). 실행 2026-11-14~15 (약 1시간 45분, 혼자 실행).
범위: 서울시 강남구 센서 (2026, 예측 대상 17개 + 입력 센서 31개, 평가 이벤트 13개). 입력 120분.
원자료: `data/processed/gangnam2026_t1_nbr_report.txt`. 예측 파일 `gangnam2026_t1_nbr_predictions.npz`(git 제외).
재현: `python -m src.analysis.t1_nbr` → `python -m src.analysis.t1_nbr_eval`

## 1. 판정 (60분 뒤, 이벤트 MAE)
| | 비교 | 차이 (mm) | 판정 |
|---|---|---|---|
| N1 주 | G-road − G-none(이웃 없음) | −0.23 [−0.57, +0.09] | **구분 불가** |
| N2 주 | G-none − M2 | −1.35 [−2.97, −0.12] | **이웃 없는 GNN도 선형을 넘음** |
| R1 재현 | G-road(시드 3·4·5) − M2 | −1.57 [−3.23, −0.24] | **재현됨** |

| 모델 (60분 뒤) | 오차 (mm) |
|---|---|
| M2 자기 이력+강우 (선형) | 31.99 |

| G-road (시드 0·1·2) | 30.41 |
| G-road (시드 3·4·5) | 30.42 |
| G-corr | 30.61 |

**결론 (미리 정한 해석 규칙대로)**
- **docs/28의 60분 뒤 우위는 시간 모델(GRU) 효과로 보고하고, 그래프 효과로는 보고하지 않는다.**
  - 이웃 연결을 모두 끊어도 선형보다 1.35 mm 나았다.
  - 이웃을 넣은 G-road와 이웃 없는 G-none은 구분되지 않았다.
- **우위는 시드를 바꿔도 재현됐다.** 두 시드 묶음의 차이는 +0.01 mm [−0.37, +0.37]이다.

## 2. 참고 (판정에 쓰지 않음)
- 30분 뒤(입력 120분)에서는 G-road − G-none이 −0.39 mm [−0.70, −0.09]로 0을 벗어났다.
  - 크기는 0.4 mm(약 2%)로 작다.
  - 같은 조건에서 GNN − M2는 구분 불가다(G-road 시드 3·4·5 −0.39 [−1.70, +0.92]).
  - 판정 지표가 아니므로 "이웃 기여"로 보고하지 않는다.
- G-corr − G-none은 60분 뒤 −0.03 [−0.52, +0.70]으로, 상관 그래프도 이웃 없음과 같았다.

## 3. 지금까지의 그림

- 근사 그래프로는 공간 구조의 효과를 확인하지 못했다는 지금까지의 결론과 같다.

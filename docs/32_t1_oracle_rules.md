# 32. 미래 강우를 미리 안다면(상한 실험): 사전 고정 규칙

고정일: 2026-11-14. **[docs/19](19_t1_st_gnn_result.md)·[docs/25](25_t1_warning_result.md) 판정과 사후 오차 분해를 본 뒤이고, 이 실험의 어떤 모델도 돌리기 전에** 정했다. 코드 기준은 [src/analysis/t1_oracle_rules.py](../src/analysis/t1_oracle_rules.py)다. 문서와 코드가 다르면 코드가 우선한다.
범위: 서울시 강남구 센서 (2026, 예측 대상 17개, 평가 이벤트 13개).

## 이미 아는 것
- 30분 뒤 큰 상승(200 mm) 첫 도달은 어떤 모델도 거의 못 잡았다(M2 1/94).
- 200 mm 이상 상승에서 M2도 평균 293 mm를 놓쳤다.
- "그 사이에 내릴 비를 몰라서"라는 설명은 **검증하지 않은 추정**이다. 이 실험으로 그 추정을 확인한다.

## 성격
- **상한(오라클) 실험**이다. 실제로 내린 미래 강우를 입력에 넣는다.
- 실시간에는 쓸 수 없다. 강우 예보가 완벽할 때 얻을 수 있는 최대 이득을 본다.

## 설정
T1([docs/17](17_t1_st_gnn_rules.md))과 같다(입력 60분, 10·30분 뒤, Ridge λ = 10).

| 모델 | 내용 |
|---|---|
| M2 | 같은 코드로 다시 만든다(T1의 M2와 같아야 한다) |
| M2F | M2 + 그 센서 최근접 강우량계의 **미래 강우**(기점 다음 블록부터 목표 블록까지 10분 강우의 log1p: 10분 뒤 1개, 30분 뒤 3개) |
| M3F (참고) | M3 + 같은 미래 강우 |

- 예측 거리마다 그 거리까지의 미래 강우만 넣는다. 목표 시각 이후의 강우는 넣지 않는다.
- GNN은 돌리지 않는다.
- 테스트: [tests/test_t1_oracle.py](../tests/test_t1_oracle.py)에서 미래 강우 열의 범위를 확인한다.

## 판정 (이 두 가지뿐, 30분 뒤)
| | 비교 | 판정 |
|---|---|---|
| O1 주 | 이벤트 MAE M2F − M2 | 상한 < 0 "미래 강우를 알면 오차가 줄어듦" / 0 포함 "구분 불가" / 하한 > 0 "나빠짐" |
| O2 주 | 큰 상승(200 mm) 첫 도달 CSI M2F − M2 ([docs/24](24_t1_warning_rules.md)와 같은 정의) | 하한 > 0 "더 잡음" / 0 포함 "구분 불가" / 상한 < 0 "덜 잡음" |

참고(판정에 쓰지 않음): 맞힘·헛경보 수, 10분 뒤, 500 mm, M3F, 200 mm 이상 상승 구간의 오차.

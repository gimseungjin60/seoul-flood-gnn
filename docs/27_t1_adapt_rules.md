# 27. 연결을 학습하는 시공간 GNN(G-adapt): 사전 고정 규칙

고정일: 2026-11-14. **T1의 예측과 판정을 보기 전이고, G-adapt로 어떤 모델도 돌리기 전에** 정했다. 코드 기준은 [src/analysis/t1_adapt_rules.py](../src/analysis/t1_adapt_rules.py)다. 이 문서와 코드가 다르면 코드가 우선한다.
범위: 서울시 강남구 센서 (2026, T1과 같은 예측 대상 17개 + 입력 센서 31개, 평가 이벤트 13개).

## 왜 하나
- 근사 그래프(도로거리, 고도 방향)는 랜덤 그래프와 같은 결과였다([docs/15](15_graph_alternatives_result.md)).
- 그래프를 미리 정하지 않고 **연결 강도 자체를 자료에서 학습**하면 나아지는지 확인한다. "왜 그래프를 학습하지 않았나"라는 질문에 대한 답이기도 하다.

## 설정
T1([docs/17](17_t1_st_gnn_rules.md))과 모두 같다(입력 60분, 10·30분 뒤, GRU, 메시지 전달 2층, 학습 설정, 시드 3개 평균). **인접 행렬만 다르다.**

| 항목 | 내용 |
|---|---|
| G-adapt 연결 | 센서마다 학습되는 벡터 두 개(차원 10). 연결 점수 = relu(받는 쪽 벡터 · 보내는 쪽 벡터). 관측된 이웃만 대상으로 softmax한다 (Graph WaveNet의 적응형 인접 행렬과 같은 형태) |
| 비교 모델 | M0~M3과 G-road는 T1 실행의 예측을 그대로 쓴다(같은 자료·폴드·평가 표본) |
| 구현 | `t1_st`의 학습·예측 코드를 그대로 쓰고 모델 클래스만 바꾼다. T1 코드는 고치지 않았다 |
| 테스트 | [tests/test_t1_adapt.py](../tests/test_t1_adapt.py): 미래 값 누수 없음, 관측 안 된 이웃은 메시지에 안 섞임 |

## 판정 (이 두 가지뿐, 30분 뒤)
| | 비교 | 판정 |
|---|---|---|
| A1 주 | G-adapt − M2 | 상한 < 0 "GNN이 선형을 넘음" / 0 포함 "구분 불가" / 하한 > 0 "선형보다 나쁨" |
| A2 보조 | G-adapt − G-road | 상한 < 0 "학습한 연결이 도로거리 그래프보다 나음" / 0 포함 "구분 불가" / 하한 > 0 "나쁨" |

참고(판정에 쓰지 않음): 10분 뒤의 같은 비교, 학습된 연결 점수 상위 쌍(폴드 1, 시드 0).

## 실행
```powershell
python -m src.analysis.t1_adapt        # G-adapt 예측
python -m src.analysis.t1_adapt_eval   # 판정 (T1 예측도 있어야 함)
python -m tests.test_t1_adapt
```

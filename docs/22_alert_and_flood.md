# 22. 경보형 평가(T3)와 침수예상도 겹치기

작성: 2026-11-09. 두 실험 모두 결과를 보기 전에 규칙을 파일에 고정했다(커밋 전). 판정은 각각 정해진 것만 했다.

## 1. 경보형 평가: 이후 60분 안에 '큰 상승'(200 mm 이상)에 도달하는가
규칙: [src/analysis/t3_alert_rules.py](../src/analysis/t3_alert_rules.py), 실행: [t3_alert.py](../src/analysis/t3_alert.py), 수치: `data/processed/gangnam2026_t3_alert_report.txt`, `_ci.csv`.
목적: 수치 예측(docs/19)이 기준선을 못 넘어, "큰 상승에 도달하는가"를 맞히는 경보 문제로 바꿔 단순 기준보다 먼저 알아챌 수 있는지 물었다. 그래프·GNN은 쓰지 않았다.

- 대상: 평가 대상 17개, 기점 상승폭이 200 mm 미만인 (시각, 센서). 이벤트 창 안 표본 20,373개(양성 1,062개, 5.2%). 시간순 5폴드(폴드 4에는 이벤트가 없어 평가 표본 없음).
- 모델: S0 현재 상승폭, S1 추세 외삽(최근 30분 변화가 이어진다고 봄), S2 최근 60분 강우, L 로지스틱 회귀(상승폭·변화·강우·시간대, 센서를 합쳐 학습).

| 이후 60분 | 평균정밀도(AP) | 판정 |
|---|---|---|
| S0 현재 상승폭 | 0.297 | |
| S1 추세 외삽 | 0.255 | |
| S2 최근 강우 | 0.116 | |
| L 로지스틱 | 0.183 | P1 L−S0 = −0.115 [−0.171, −0.039] **L이 나쁘다** · P2 L−S1 = −0.072 [−0.136, −0.011] **L이 나쁘다** · P3 L−S2 = +0.067 [+0.046, +0.118] L이 낫다(참고) |

- **결론: 경보형으로도 예측이 된다고 말할 수 없다.** "P1과 P2가 모두 L이 낫다"가 조건이었는데 둘 다 반대였다. 지금 이미 많이 올라 있으면 곧 큰 상승이 된다는 단순 규칙이 학습 모델보다 잘 맞았다.
- 참고: L의 재현율 84%, 헛경보율 73%(임계는 학습 구간 음성 점수의 90% 분위). 30분 이내로 줄이면 L과 S0, S1은 구분되지 않았다(참고).
- 한계: 이벤트 13개, 한 시즌. 평소 수위 기준(요일x시 중앙값)에 평가 구간이 들어 있다. 위험이 아니라 평소 대비 상승이다.

## 2. 침수예상도 겹치기
코드: [src/analysis/flood_overlay.py](../src/analysis/flood_overlay.py), 수치: `data/processed/gangnam2026_flood_overlay_report.txt`, `gangnam2026_sensor_flood_overlay.csv`.

- 자료: 서울시 풍수해 침수예상도 shp 6개(`data/raw/flood/침수예상도/`, git 제외). 레이어는 침수심 구간별 면이다(1 = 침수심1(0.5 m 미만으로 추정), 2 = 0.5~1.0 m, 3 = 1.0~1.5 m, 4 = 1.5~2.0 m, 5 = 2.0~3.0 m, 6 = 3.0 m 이상). 파일 수정일은 2023-02-15이고 좌표계 정보(.prj)가 없어 EPSG:5186으로 가정했다. OpenAPI `floodingDs`는 침수단계·공간id만 주고 좌표가 없어 이어 붙이지 못했다(단계가 1~8이라 파일의 6구간과 같은지도 확인되지 않음).
- 센서 54개 중 25개가 침수심1 영역 안, 29개는 밖(가까운 예상 면까지 중앙 104 m). **침수심 2 이상 영역에는 센서가 하나도 없다.** 침수심1 영역이 넓어(약 58 km²) 안/밖 구분이 약한 정보다.
- 판정(규칙 고정): 기록 안정 센서 39개를 안(19)/밖(20)으로 나눠 50 mm 이상 비 5건에서의 최대 상승 중앙값을 비교했다. 안 232 mm, 밖 144 mm, 차이 +88 mm [−58, +317] → **구분 불가**. 거리와 반응의 순위상관은 −0.15(p=0.35, 참고).
- 해석: 침수 예상 영역 안의 센서가 더 크게 오르는 경향은 보이지만 이 자료(센서 39개, 사건 5건)로는 확인되지 않았다. 침수예상도는 지표면 침수 시뮬레이션이라 하수관 수위와 다른 것이므로, 맞지 않는다고 해서 이상한 결과도 아니다.
- 사용: 대시보드 지도 툴팁에 "침수예상도: 영역 안/밖(가까운 면까지 거리)"을 배경 정보로 표시한다. 위험 판정이 아니다.

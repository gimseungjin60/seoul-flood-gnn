# 20. 센서 간 시차 분석: 사전 고정 규칙

고정일: 2026-11-14. 이 분석의 어떤 값도 계산하기 전에 정했다. **T1 시공간 GNN 판정(docs/17)도 아직 실행 전이다.** 코드 기준은 [src/analysis/lead_lag_rules.py](../src/analysis/lead_lag_rules.py)의 상단 docstring과 상수다. 이 문서와 코드가 다르면 코드가 우선한다.
범위: 서울시 강남구 센서 (2026-06-01~08-31, pool 48개, 평가 이벤트 13개).

## 왜 하나
- T1 시공간 GNN은 "위쪽 물이 몇십 분 뒤 아래로 내려온다"는 **시간차**를 그래프가 전달해 준다고 가정한다.
- 그 시간차가 자료에 실제로 있는지 **모델 없이** 확인한다. 모델 비교가 아니라 자료 진단이고, T1 판정에는 쓰지 않는다.

## 방법
| 항목 | 내용 |
|---|---|
| 자료 | 2026 1분 수위(보간 없음), pool 48개, 평가 이벤트 13개, 센서별 최근접 강우량계의 10분 강우 |
| 사건 창 | 이벤트 시작 − 60분 ~ 끝 + 3시간. 기준 수위 = 시작 전 60분 중앙값 |
| 상승 | (수위 − 기준) mm, 중심 10분 이동평균 |
| 유효한 센서-사건 | 창 안 관측률 70% 이상, 최대 상승 50 mm 이상(상승 단계 1, [docs/16](16_rise_levels.md)) |
| 시각 | **절반까지 오른 시각**(최대 상승의 50%에 처음 도달). 참고로 최고 수위 시각 |
| 강우 보정 | 반응 지연 = 센서의 절반 시각 − 그 강우량계의 누적 강우 절반 시각. 쌍의 시차 = 두 센서의 반응 지연 차이 (강우 도착 차이를 뺌) |
| 평가 쌍 | 두 센서가 모두 유효한 사건이 4개 이상인 쌍 |
| 일관된 시차 쌍 | 사건 중앙값이 10분 이상이고, 사건의 75% 이상에서 같은 센서가 먼저 오름 |
| 도로 이웃 쌍 | 둘 중 하나가 다른 하나의 도로거리 최근접 5개 안 (T1 G-road와 같은 기준) |

## 판정 (이 두 가지뿐)
우연 기준: 쌍마다 사건별 시차의 방향(부호)을 무작위로 뒤집어 일관된 시차 쌍 비율을 다시 센다(2000회, 시드 0).

| | 대상 | 판정 |
|---|---|---|
| L1 주 | 도로 이웃 쌍 | 일관된 시차 쌍 비율 > 우연의 95백분위수 → "도로 이웃 사이 시차 신호 있음" / 아니면 "우연 수준과 구분 불가" |
| L2 보조 | 전체 평가 쌍 | 같은 방식 |

참고(판정에 쓰지 않음): 30분 이상 시차 쌍 수, 센서별 반응 지연 분포, 시차와 도로거리의 순위 상관(이벤트 복원추출 95% 구간), 강우 보정 전 시차, 최고 수위 시각 기준 집계.

## 한계
- 이벤트가 13개뿐이다. 신규 센서는 75~87분 주기 공백 때문에 유효 사건이 적을 수 있다.
- 강우는 10분 단위라 반응 지연에 10분 정도 오차가 있다.
- 센서 쌍끼리 겹치므로 쌍들은 독립이 아니다. 어느 쌍도 실제 관로 연결은 아니다.

# 26. 더 먼 예측(입력 120분, 60분 뒤): 사전 고정 규칙

고정일: 2026-11-14. **T1(입력 60분)의 예측과 판정을 보기 전이고, 이 확장으로 어떤 모델도 돌리기 전에** 정했다. 코드 기준은 [src/analysis/t1_long_rules.py](../src/analysis/t1_long_rules.py)다. 이 문서와 코드가 다르면 코드가 우선한다.
범위: 서울시 강남구 센서 (2026, T1과 같은 예측 대상 17개 + 입력 센서 31개, 평가 이벤트 13개).

## 왜 하나
- 시차 분석([docs/21](21_lead_lag_result.md))에서 반복되는 센서 간 시차 141개 중 **78개가 60분 이상**이었다.
- T1([docs/17](17_t1_st_gnn_rules.md))은 지난 60분만 보기 때문에 이 관계를 쓸 수 없다.
- 그래서 **지난 120분**을 보고 **60분 뒤**를 예측할 때 시공간 GNN이 강우+자기이력 선형(M2)을 넘는지 확인한다.
- 이 확장의 동기는 docs/21 결과에서 왔다. T1 판정과 별개로 보고하며, T1 판정은 바꾸지 않는다.

## 설정
T1과 모두 같고, 두 가지만 바꾼다.

| 항목 | T1 | 이번 확장 |
|---|---|---|
| 입력 창 | 60분 (6블록) | **120분 (12블록)** |
| 예측 거리 | 10분, 30분 | **30분, 60분** |

- 자기 이력 선형 모델(M1~M3)의 특징은 창 길이에 맞춰 늘어난다(a[t] − a[t−k], k = 1..11).
- 미래 강우는 쓰지 않는다. 대시보드에 강우 예보가 없기 때문이다.
- 구현: `src.analysis.t1_st`의 상수(입력 창, 예측 거리, 출력 파일)만 바꿔 같은 코드로 실행한다. T1 코드는 고치지 않았다.
- 누수 테스트: [tests/test_t1_long.py](../tests/test_t1_long.py)에서 T1 누수 테스트를 확장 설정으로 다시 돌린다.

## 판정 (이 두 가지뿐, 60분 뒤)
지표와 부트스트랩은 T1과 같다(이벤트 MAE, 이벤트 13개 2000회 복원추출, 차이의 95% CI).

| | 비교 | 판정 |
|---|---|---|
| D1 | G-road − M2 | 상한 < 0 "GNN이 선형을 넘음" / 0 포함 "구분 불가" / 하한 > 0 "선형보다 나쁨" |
| D2 | G-corr − M2 | D1과 같음 |

참고(판정에 쓰지 않음): 30분 뒤의 같은 비교, M3 − M2, M2 − M0, T1(입력 60분)의 30분 뒤 수치를 나란히 비교.

## 실행
```powershell
python -m src.analysis.t1_long        # 전체
python -m src.analysis.t1_long_eval   # 판정
python -m tests.test_t1_long
```

## 한계
- 이벤트가 13개뿐이다. 그래프는 실제 관로 연결이 아니다.
- 60분 뒤 수위는 그 사이에 내릴 비에 크게 좌우되는데, 미래 강우는 쓰지 않는다.
